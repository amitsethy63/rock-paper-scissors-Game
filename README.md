# rock-paper-scissors-Game
✊✋✌️ Rock Paper Scissors Game

📌 Project Overview

This is a simple and interactive Rock Paper Scissors game developed using HTML, CSS, and JavaScript. The player competes against the computer by choosing rock, paper, or scissors. The game automatically generates the computer's choice and displays the result.

🎯 Features

- 🎮 Interactive gameplay.
- 🤖 Random computer selection.
- 🏆 Automatic winner detection.
- 📊 Live score tracking for the player and computer.
- 🔄 Draw detection when both choices are the same.
- 🎨 Simple and user-friendly interface.

🛠️ Technologies Used

- HTML5 – Structure of the game.
- CSS3 – Styling and layout.
- JavaScript – Game logic, random choices, and score updates.

🚀 How to Run the Project

1. Download or clone this repository.
2. Make sure index.html, style.css, app.js, and the Images folder are in the correct locations.
3. Open index.html in your web browser.
4. Click Rock, Paper, or Scissors to play against the computer.

📜 Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both players choose the same option, the game is a draw.
